# 任意の応援（アプリ内課金）の設定・確認手順

## 1. 方針

- アプリは**無料・広告なし**で公開する。機能は全て無料で、応援しても何も変わらない（機能開放には使わない）。
- 応援は、Google Playの課金システム（Play Billing）で受け付ける。Playの決済ポリシーにより、アプリ内で支援金を
  受ける場合はPlay課金の使用が必要（免税の寄付団体向けの例外を除く）。外部の決済ページへ誘導しない。
- 商品は「消費型」（購入のたびに消費され、何度でも購入できる）。購入後にアプリ側で即消費するため、購入の承認
  （acknowledge）も同時に行われ、3日以内の自動返金を防ぐ。
- サーバー側の処理は無い（購入状態を保存・確認しない）。
- 旧仕様（100円の有料公開＋購入者特典）は、当面使わない。`/entitlement/*` と設定画面の「購入者特典」は、
  将来の「Pro」等のために残し、画面上は非表示にしている（`index.html` の `#entitlementSection`）。

## 2. 全体の仕組み

```
設定タブ(Web)                    Androidアプリ(MainActivity)             Google Play
 initSupportSection()  ───────►  AndroidBridge.requestSupportProducts()
                                  SupportBilling: 商品の詳細を問い合わせ  ───►  価格・名称
 __onSupportProducts(json) ◄───   [{id, price, title}]
 ボタン表示（商品が1件以上あるときだけ）
 purchaseSupport(id)  ─────────►  AndroidBridge.purchaseSupport(id)  ───►  購入画面
 __onSupportPurchaseResult ◄───   success / pending / canceled / error  ◄───  結果 → 消費
```

- Webの画面（`src/public/js/settings.js`）は、`AndroidBridge` が無い環境（ブラウザ等）や、商品を1件も取得できない場合は、
  セクションごと表示しない。
- 購入トークン等の機密情報は、Web側へ渡さない。

## 3. Play Consoleでの設定（手動）

1. **決済プロファイル**（販売者情報）を設定する。無料アプリでもアプリ内課金を受けるには必要。
2. アプリの**内部テスト**へ、課金ライブラリ入りのAAB（署名済み）を一度アップロードする（商品の作成に必要）。
3. 「収益化 → 商品 → アプリ内アイテム（買い切り）」で、次の商品を作成する。**商品IDは変更できない**ため、
   アプリのコード（`SupportBilling.kt` の `SUPPORT_PRODUCT_IDS`）と完全に一致させる。

   | 商品ID | 価格 | 名称（日本語）案 | 名称（English）案 |
   |---|---|---|---|
   | `support_100` | 100円 | ささやかな応援 | A small thank-you |
   | `support_300` | 300円 | お茶1杯分の応援 | A cup of tea |
   | `support_500` | 500円 | コーヒー1杯分の応援 | A cup of coffee |
   | `support_1000` | 1,000円 | しっかり応援 | A big thank-you |

   - 購入オプションは**消費型（繰り返し購入可）**にする。
   - 説明文の例: 「お遍路みちしるべの開発を応援します。機能は変わりません。」
   - 名称は端末の言語に応じてPlayが表示する。他の言語も追加できる（任意）。
   - 価格は日本円で設定し、他の国は自動換算でよい。
4. 商品を**有効化**する。
5. **ライセンステスター**（テスト用のGoogleアカウント）を登録する。テスターは課金が請求されない
   （テスト購入になる）。

## 4. 動作確認（内部テスト）

Playからインストールした実機（テスターのアカウント）で確認する。ローカルのデバッグ版は、商品が
取得できないため、応援セクションは表示されない（正しい動作）。

- [ ] 設定タブに「開発者を応援」が表示され、4つの金額（円）が表示される
- [ ] 金額を押すとPlayの購入画面が開く（テスト購入の表示）
- [ ] 購入すると「ご支援ありがとうございます」が表示される
- [ ] 同じ金額をもう一度購入できる（消費されている）
- [ ] 購入画面を閉じても（キャンセル）、何も表示されず、ボタンが押せる状態に戻る
- [ ] 機内モードなどで商品を取得できない場合は、応援セクションが表示されない
- [ ] 英語などに端末の言語を変えても、名称・文言が切り替わる
- [ ] 購入後にアプリを終了して起動し直しても、問題なく使える（消費し損ねた購入は、起動時に回収される）

## 5. ストア・申告

- **データセーフティ**: 購入はGoogle Playが処理する。「購入履歴」等を当方が収集しない前提だが、Play Consoleの
  質問の意図に沿って、実態に合わせて回答する。位置情報、Firebase Analytics・Crashlyticsの申告は、引き続き必要。
- **プライバシーポリシー**: 任意の応援の項目を追加済み（`src/public/privacy.html`）。
- **ストア説明**: 「広告なし」「無料」「任意の応援」を明記する（`store-listing.md`）。
- 価格は「無料」に設定する（後から有料にはできない）。

## 6. 注意

- Play課金は、Androidアプリ内でのみ動く。WebのURLを直接ブラウザで開いた場合は、応援セクションは出ない。
- 返金（利用者の操作・Playの規定による）は、Play Consoleで確認できる。返金されても、機能には影響しない。
- 商品の価格・名称を変える場合は、Play Consoleで変更できる（商品IDは変更不可）。商品を増やす・減らす場合は、
  `SUPPORT_PRODUCT_IDS` を変更してアプリを更新する必要がある。
